# Portfolio Notes

This repository is a public explanation of a system I built during my internship at Tricolage.

The original system was created for internal company use, so I have intentionally left out production source code, real supplier records, internal screenshots, credentials, private prompts, and other company-specific information.

The JavaScript example and CSV in the `examples` folder are synthetic examples created only to demonstrate the general type of workflow described in the case study.

I can discuss the system architecture, Google Apps Script workflow, Gemini integration, prompt design, validation logic, queueing, error handling, and the tradeoffs I made while building the project.
